SimpleLink Zephyr v4.4.0-ti-01.01.00 Release

Texas Instruments Zephyr GitHub repository is the downstream fork of Zephyr and is the starting point for developers wanting to start developing Zephyr applications.

This SimpleLink™ downstream Zephyr release is production grade and the team is also working on upstreaming this content to mainline Zephyr.

To quickly get started, see the Zephyr Trainings on SimpleLink Academy.

Dependencies

Zephyr v4.4.0 STS

Note

Flashing a Zephyr 4.4 .elf/.out file containing a TLS header segment will fail when using UniFlash or CCS. For CCS (version 21.0) and UniFlash (version 9.6.0) or earlier, use a .hex file instead.
