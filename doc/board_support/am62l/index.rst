Board Support
#############

Overview
********

AM62L is a TI processor from the AM62 family targeting low-power Linux and
Zephyr co-processor applications. It is an Arm Cortex-A53 based device.

Supported Boards
****************

.. list-table::
   :header-rows: 1
   :widths: 20 20 40 20

   * - Board ID
     - Device
     - CPU
     - Product page
   * - ``am62l_evm``
     - AM62L
     - Arm Cortex-A53 @ 1.4 GHz
     - `TMDS62LEVM <https://www.ti.com/product/AM62L>`_
