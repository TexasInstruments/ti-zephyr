Board Support
#############

Overview
********

AM13 is a TI processor family targeting real-time industrial and automotive
applications. The AM13E230 is a single-core Arm Cortex-M33 based device.

Supported Boards
****************

.. list-table::
   :header-rows: 1
   :widths: 20 20 40 20

   * - Board ID
     - Device
     - CPU
     - Product page
   * - ``lp_am13e230``
     - AM13E230
     - Single-core Arm Cortex-M33 @ 200 MHz
     - `AM13 <https://www.ti.com/product/AM13E23019>`_
