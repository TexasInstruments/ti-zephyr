Step 2: Board Setup
###################

.. note::

   This page is a placeholder. Detailed board setup steps will be added once
   the AM62L SDK installer is finalized.

AM62L boots from an SD card. Download TI's official `WIC image
<https://dr-download.ti.com/software-development/software-development-kit-sdk/MD-YjEeNKJJjt/11.02.08.02/tisdk-default-image-am62lxx-evm-11.02.08.02.rootfs.wic.xz>`_
and write it to an SD card using an etching tool. Insert the SD card into the
AM62L EVM (``am62l_evm``).
