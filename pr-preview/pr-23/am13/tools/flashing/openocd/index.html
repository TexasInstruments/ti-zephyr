OpenOCD

Note

This page is a placeholder. More details will be added later.

OpenOCD is the open-source on-chip debugger that west flash uses to program AM13 boards. It is included in the Zephyr SDK installation.

Flash an application by running west flash from the zephyr folder and pointing it at the SDK’s OpenOCD:

west flash --openocd ../openocd/src/openocd --openocd-search ../openocd/tcl/

See Getting Started for a complete build and flash walkthrough.
