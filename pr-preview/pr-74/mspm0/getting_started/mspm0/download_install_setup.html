Step 1: Download, Install and Setup the SDK and Tools

Note

This guide covers Ubuntu version 22.04 LTS and later.

The SDK installer places the Zephyr workspace, toolchain and flashing tools in <sdk-install-dir>. A few host packages must still be installed; see Setup below.

Download

Download the MSPM0 SDK installer from MSPM0-ZEPHYR-SDK page

Install

Run the installer and follow its prompts. The SDK is installed to <sdk-install-dir>, which the following steps refer to.

Once the installer is downloaded on the system, open the properties of the .run file and toggle the option for Executable as Program to on

Run the installer and follow the below instructions:

Opening Screen of the installer (Click Forward)

Choose installation directory (by default it chooses <home>/ti/<SOC_SDK>) -

Wait for the Installation to complete -

Click finish -

The SDK is installed

Setup

Run the setup script once after the installation:

cd <sdk-install-dir>
source setup_env.sh

The script checks that the host packages are present (git, cmake, ninja-build, gperf, python3 and python3-venv; it prints the sudo apt-get command to install any that are missing and exits, it does not install them itself), creates a Python virtual environment in <sdk-install-dir>/.venv with west and the Python requirements of Zephyr (Python 3.12 or later is required), and prepares the bundled host tools.

In every new terminal, activate the environment before building or flashing:

source <sdk-install-dir>/.venv/bin/activate

Activating the environment sets ZEPHYR_BASE and ZEPHYR_SDK_INSTALL_DIR, so west finds the Zephyr tree and the toolchain in <sdk-install-dir>. No global CMake registry entries are written.
