#include <zephyr/drivers/rtc/rtc_ti_mspm0.h>

Register a callback for the RTC interval timer (RTCTEV).

Configures the interval at which the RTCTEV interrupt fires and registers a callback to be invoked on each event. Pass callback as NULL to disable the interval timer.

Parameters
devRTC device instance
intervalInterval selection (rtc_mspm0_interval)
callbackFunction to call on each interval event, or NULL to disable
user_dataUser context pointer passed to the callback
Return values
0on success

#include <zephyr/drivers/rtc/rtc_ti_mspm0.h>

Register a callback for a prescaler timer (RT0PS or RT1PS).

Configures the periodic interrupt interval for the selected prescaler timer and registers a callback to be invoked on each event. Pass callback as NULL to disable the prescaler timer interrupt.

Use values from rtc_mspm0_rt0ps_interval when timer is RTC_MSPM0_PS_TIMER_0, and values from rtc_mspm0_rt1ps_interval when timer is RTC_MSPM0_PS_TIMER_1.

Parameters
devRTC device instance
timerPrescaler timer selection (rtc_mspm0_ps_timer)
intervalInterval value for the selected timer
callbackFunction to call on each timer event, or NULL to disable
user_dataUser context pointer passed to the callback
Return values
0on success
