Detailed Description

Callback struct for periodic advertising sync events.

This struct defines the callback functions that are invoked for various periodic advertising sync events. These include when the sync is successfully established, terminated, when data is received, state changes, BIG info reports, and IQ samples from the periodic advertising.

Note
Used in bt_le_per_adv_sync_cb_register function.
