Detailed Description

nPM2100-specific GPIO Flags

The drive flags are encoded in the 8 upper bits of gpio_dt_flags_t as follows:

  • Bit 8: Drive strength (0=1mA, 1=6mA)
  • Bit 9: Debounce (0=OFF, 1=ON)
