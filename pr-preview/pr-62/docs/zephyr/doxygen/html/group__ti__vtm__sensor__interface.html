enum ti_vtm_sensor_trigger_type

#include <zephyr/drivers/sensor/ti_vtm.h>

VTM-specific thermal trip trigger types.

Three independent temperature trip thresholds, each triggering an interrupt when the die temperature crosses the configured boundary. Configure thresholds via sensor_attr_set() with vtm_sensor_attribute, then register handlers via sensor_trigger_set().

Enumerator
TI_VTM_TRIG_TH0 

Low temperature trip (LT_TH0): fires when temp falls below threshold.

TI_VTM_TRIG_TH1 

High temperature trip (GT_TH1): fires when temp rises above threshold.

TI_VTM_TRIG_TH2 

Critical temperature trip (GT_TH2): fires when temp rises above threshold.
