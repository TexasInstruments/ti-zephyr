inlinestatic

#include <zephyr/net/mld.h>

Join a given multicast group.

Parameters
ifaceNetwork interface where join message is sent
addrMulticast group to join
Return values
0If multicast address was registered and joined successfully.
-ENETDOWNIf multicast address was registered but not joined yet due to network interface being down. The address will be joined when interface is up again. This is non-fatal return code, the caller should still release the address with net_ipv6_mld_leave() if no longer needed.
OtherAny other error should be considered fatal, multicast address was not registered for the interface.
