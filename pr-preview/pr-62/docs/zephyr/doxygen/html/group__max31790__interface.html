Detailed Description

Maxim MAX31790 6-Channel PWM-Output Fan RPM Controller.

The MAX31790 provides fan fault monitoring and fan speed (RPM) sensing. Fan speed uses the standard SENSOR_CHAN_RPM channel.

Enumerator
SENSOR_CHAN_MAX31790_FAN_FAULT 

Fan fault status bitmask.

Each bit indicates a fault for the corresponding fan (1-6). Bit 0 = fan 1 fault, bit 1 = fan 2 fault, ..., bit 5 = fan 6 fault.

  • sensor_value.val1 is the 6-bit fault mask.
  • sensor_value.val2 is unused (always 0).
