◆ ti_eqep_alarm_channel

enum ti_eqep_alarm_channel

#include <zephyr/drivers/counter/ti_am3352_eqep.h>

EQEP Event Source Identifiers (Logical Channels).

These represent different interrupt sources within the EQEP peripheral, not independent hardware channels. Each corresponds to a distinct functional unit that can generate events and trigger callbacks through the counter API.

Enumerator
TI_EQEP_ALARM_CHAN_COMPARE 

Alarm for position compare unit.

Alarm for strobe event.
