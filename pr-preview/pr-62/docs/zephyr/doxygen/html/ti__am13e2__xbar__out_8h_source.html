9/*
10 * Packed mux-control cell for the AM13E2 output X-BAR: encodes which
11 * physical OUTPUTXBARx (0-7), which GxSEL group (0/1), and which one-hot
12 * bit (0-31) within that group's 32-bit source-select field a set/get_state/
13 * disconnect call addresses. One packed cell lets a single output-xbar
14 * device instance cover all 8 outputs.
15 */
