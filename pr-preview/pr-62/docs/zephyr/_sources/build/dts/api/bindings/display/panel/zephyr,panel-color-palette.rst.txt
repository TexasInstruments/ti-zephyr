zephyr,panel-color-palette
##########################

.. sidebar:: Overview

   :Name: ``zephyr,panel-color-palette``
   :Vendor: :ref:`Zephyr Project <dt_vendor_zephyr>`
   :Used in: :zephyr:board-catalog:`List of boards <#compatibles=zephyr,panel-color-palette>` using
               this compatible

Description
***********



.. code-block:: none

   Common color palette settings for display panels.

Examples
********

.. code-block:: dts

   color-palette {
     compatible = "zephyr,panel-color-palette";
     colors = <ARGB8888(255, 0, 0, 255)   /* red */
               ARGB8888(0, 255, 0, 128)   /* green, 50% alpha */
               PANEL_COLOR_PALETTE_NULL   /* Empty entry */
               ARGB8888(0, 0, 255, 255)>; /* blue */
   };
