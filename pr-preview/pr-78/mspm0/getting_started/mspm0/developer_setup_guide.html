Getting Started from GitHub

Use this guide to build the MSPM0 SDK workspace from the ti-zephyr repository on GitHub instead of the SDK installer. The installer ships the toolchain, host tools and a ready west workspace; here you assemble them yourself. Once the workspace is ready, continue with Step 3: Build Hello World Example and Step 4: Flash Hello World Example.

Note

This guide covers Ubuntu 22.04 LTS and later.

Install the host dependencies

Update the system:

sudo apt update
sudo apt upgrade

The minimum versions of the main dependencies are:

Tool

Min. Version

CMake

3.28.0

Python

3.12

Devicetree compiler

1.4.6

Install the packages with apt:

sudo apt install --no-install-recommends git cmake ninja-build gperf \
ccache dfu-util device-tree-compiler wget python3-dev python3-venv python3-tk \
xz-utils file make gcc gcc-multilib g++-multilib libsdl2-dev libmagic1

Check the installed versions against the table above:

cmake --version
python3 --version
dtc --version

Get the workspace

  1. Create and activate a Python virtual environment:

    python3 -m venv ~/zephyrproject/.venv
source ~/zephyrproject/.venv/bin/activate

  2. Install west, the Zephyr workspace manager:

    pip install west

  3. Create the workspace from the ti-zephyr manifest and fetch all modules. v4.4.0-ti-01.00.00.02 is the release tag; use main for the latest development state:

    west init -m |ti_repo_url|.git --mr v4.4.0-ti-01.00.00.02 ~/zephyrproject
cd ~/zephyrproject
west update

  4. Install the Python requirements of Zephyr:

    west packages pip --install

  5. Register the Zephyr checkout in the CMake user package registry (~/.cmake/packages), so find_package(Zephyr) finds it. The SDK installer does not need this step.

    west zephyr-export

Install the Zephyr SDK toolchain

The Zephyr SDK provides the cross-compilers, assembler, linker and the other programs needed to build for the target. Install version 1.0.1, the version shipped with the SDK installer:

cd ~/zephyrproject/zephyr
west sdk install --version 1.0.1

Install OpenOCD

OpenOCD is required to flash MSPM0 boards. Install the build dependencies and clone the OpenOCD sources:

sudo apt install libusb-1.0-0-dev libhidapi-dev
cd ~/zephyrproject

git clone https://github.com/openocd-org/openocd

Build and install it. sudo make install puts OpenOCD on the PATH, so west flash finds it without extra options:

cd openocd
git submodule update --init --recursive
./bootstrap
./configure --enable-xds110
make
sudo make install

Next steps

In every new terminal, activate the environment before building or flashing:

source ~/zephyrproject/.venv/bin/activate

Build and flash the Hello World sample from ~/zephyrproject/ti-zephyr as described in Step 3: Build Hello World Example and Step 4: Flash Hello World Example.
