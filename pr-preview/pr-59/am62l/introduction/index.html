Zephyr SDK for AM62L
  • Introduction

Introduction

Zephyr SDK is a west workspace based SDK that provides TI-specific samples and tests along with upstream Zephyr RTOS.

Block Diagram

Given below is a block diagram of the SW modules in this SDK,

Software Components

The main software components in the block diagram are described below. Except for the toolchain, they are part of the Zephyr workspace, whose contents are defined by the west manifest (west.yml) in ti-zephyr.

Software Component

Documentation Page

Description

Toolchain (Zephyr SDK bundle)

Zephyr SDK

Cross-compilation toolchain and host tools from the Zephyr SDK bundle, used to build the SDK and applications. It is installed by the SDK installer; see Getting Started.

Bootloader (MCUboot)

MCUboot

MCUboot secure bootloader, imported from TI’s MCUboot fork into bootloader/mcuboot of the workspace.

Tools

Tools and Utilities

Host tools used while developing with the SDK, such as west for workspace management, building, flashing and debugging, and the flashing tools for the target SoC.

Modules (Middleware, stacks, HALs)

Zephyr Modules

Hardware abstraction layers (such as hal_ti), middleware and protocol stacks (such as LVGL, mbed TLS, littlefs and OpenThread), imported as west projects under modules/.

Vanilla Zephyr

Zephyr Documentation

The Zephyr RTOS (kernel, subsystems, device drivers, devicetree, board and SoC support) from TI’s Zephyr repository (TexasInstruments/zephyr), at the revision pinned by the west manifest.

ti-zephyr

Samples, Tests and Applications

The SDK’s own Zephyr module and west manifest repository. It provides the TI-specific samples, tests, applications, devicetree bindings and out-of-tree drivers.

Directory Structure

Given below is an overview of the directory structure to help you navigate the SDK and related tools.

The SDK is a west workspace. <sdk-install-dir> is the directory the SDK installer installs it to, as used in Getting Started.

Directory

Description

<sdk-install-dir>/zephyr/

Zephyr RTOS. directory.

<sdk-install-dir>/ti-zephyr/

The ti-zephyr module and west manifest repository, described below.

<sdk-install-dir>/modules/

Zephyr modules imported by the manifest: HALs, middleware and stacks.

<sdk-install-dir>/bootloader/

MCUboot (bootloader/mcuboot).

<sdk-install-dir>/tools/

Helper tools imported by the manifest, for example net-tools.

The ti-zephyr module is organized as follows:

ti-zephyr/

Description

west.yml

West manifest; pins Zephyr and every TI-relevant module.

zephyr/module.yml

Zephyr module description that registers the devicetree root, samples and tests of this repository with the build system.

drivers/

Out-of-tree drivers.

samples/

TI samples; see Samples, Tests and Applications.

dts/, include/, lib/

Devicetree bindings, public headers and libraries.

applications/

TI reference applications; see Samples, Tests and Applications.

cmake/

Shared CMake extensions.

modules/

TI modules pending their own west projects.

scripts/

Development tooling.

doc/

Sphinx sources of this documentation.
