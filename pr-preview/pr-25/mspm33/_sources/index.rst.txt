TI Zephyr Documentation
########################

Welcome to **TI Zephyr**. This repository contains TI-specific samples and
tests built on top of the `Zephyr RTOS <https://zephyrproject.org>`_
(|zephyr_ver|), targeting Texas Instruments LaunchPad development boards.
