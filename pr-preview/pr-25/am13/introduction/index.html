TI Zephyr
  • Introduction

Introduction

TI Zephyr is a west workspace module maintained by Texas Instruments that provides TI-specific samples and tests on top of the upstream Zephyr RTOS.

What It Contains

This repository does not fork or modify the Zephyr kernel. It contains:

  • Samples — standalone applications demonstrating TI peripheral drivers and hardware features (samples/)

  • Tests — automated test suites for TI-specific hardware (tests/)

All samples and tests are built against Zephyr v4.4.0-ti.

Relation to Main Zephyr

TI Zephyr is registered as a Zephyr module via zephyr/module.yml. The west manifest (west.yml) pins the TI fork of Zephyr at v4.4.0-ti and imports the standard set of upstream Zephyr modules (mbedtls, cmsis, mcuboot, etc.).

For core Zephyr documentation — kernel, device drivers, build system, and boards — refer to the main Zephyr documentation.
