Real-Time Control Library

Overview

The real-time control library is a set of motor control building blocks: coordinate transforms, filters, controllers and utilities. It is ported from the realtimelib of the AM13 SDK. The modules are plain C with fixed float32_t interfaces and are used by including their headers.

Enable CONFIG_TI_REALTIMELIB (it depends on the AM13E SoC series and the FPU, and selects CONFIG_TI_MATHLIB_FASTRTS):

#include <park.h>
#include <pi.h>

PARK_Obj park_obj;
PARK_Handle park = PARK_init(&park_obj, sizeof(park_obj));

PARK_setup(park, rotor_angle_rad);

Each module has an _Obj structure that the caller owns, and an _init() function that takes a pointer to it and its size. _init() returns NULL if the buffer is too small.

Modules

Group

Modules

Transforms

clarke, park, ipark, svgen, volts (voltage calculation and reconstruction)

Filters

filter_fo (first order), filter_so (second order), notch, offset

Control

pi, pid, pr (proportional resonant), fwc (field weakening), vs_freq (volts per frequency), vib_comp (vibration compensation), dclink_ss (DC link single shunt current reconstruction)

Utilities

angle_gen, rampgen, traj (trajectory), cpu_time, types

Math

math_types.h: shared types, constants and helper macros

TMU acceleration

math_types.h includes <mathlib/fastrts_tmu.h> and maps sinf, cosf, asinf, acosf, atanf, atan2f, expf, logf and sqrtf to the TMU functions, as the SDK does. This applies to code that includes the library headers, so PARK_setup() and the other inline functions run on the TMU.

The TMU is less accurate than the C library for expf: the result is wrong for large inputs (about 77 % high at 13.86). See Math Library (TMU). No module of this library calls expf or logf, but an application that includes these headers and calls them gets the TMU versions.

Not included

The SDK realtimelib has 33 modules. These are not ported yet:

Modules

Reason

dead_time_comp, ipd, ti_tune, est_lib (FAST), flux_obs

Delivered as prebuilt libraries only.

esmo, speedfr, vsf

Need USER_Params, which is defined with the FAST estimator.

vsf, mtpa

Need motor constants from the application configuration.

datalog, motorvision

Need an application hardware layer (a device header, a UART).

Samples and tests

  • tests/lib/realtimelib is a ztest suite that checks the Clarke, Park and inverse Park transforms, space vector generation, the PI controller and the first-order filter. It runs on hardware because the sine and cosine calls use the TMU.

The SDK has no example or test for this library.
