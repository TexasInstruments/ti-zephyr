Getting Started
###############

Set up the SDK for |soc_name|, then build and flash the Hello World sample.
Choose one way to get the SDK:

* **SDK installer**: ships the toolchain, host tools and a ready west
  workspace. Follow Steps 1 to 4 below.
* **GitHub**: clone ``ti-zephyr`` and assemble the workspace yourself. Follow
  :ref:`Getting Started from GitHub <ti-zephyr-github-setup>` instead of Step 1,
  then continue with Step 3.
