Step 1: Download, Install and Setup the SDK and Tools

Note

This page is a placeholder. The download location and installation steps will be added once the AM62L SDK installer is finalized.

This guide covers Ubuntu version 24.04 LTS and later.

The SDK installer places the components Zephyr requires (the Zephyr workspace, toolchain and flashing tools) where they are needed, so no separate dependency installation is required.

Download

Download the AM62L SDK installer from AM62L-ZEPHYR-SDK page

Install

Run the installer and follow its prompts. The SDK is installed to <sdk-install-dir>, which the following steps refer to.
