TI Motor Control LVGL UI

Overview

A four-screen LVGL 9.x motor-control user interface targeting the LP-AM13E230 LaunchPad with the Waveshare 3.5” RPi LCD (F) display shield.

Screens:

  • Run — start/stop, direction, speed setpoint dial and live RPM odometer.

  • Trend — live chart of speed, current and temperature over time.

  • Faults — fault log table with clear action.

  • Config — drive configuration (current limit, ramp rate, etc.).

Hardware requirements

  • LP-AM13E230 LaunchPad development kit.

  • Waveshare 3.5” RPi LCD (F) — ST7796S SPI display (320×480) and GT911 capacitive touch, connected via the LP-AM13E230 BoosterPack headers.

Building

From the Zephyr workspace root:

west build -b lp_am13e230 applications/motor_control_app \
    --shield waveshare_3_5_rpi_lcd_f

The shield is mandatory; the build will fail without it (display and touch nodes are defined by the shield overlay).

Flashing

west flash
