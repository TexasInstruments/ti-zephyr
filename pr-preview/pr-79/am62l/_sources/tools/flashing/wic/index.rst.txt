WIC based flashing
##################

AM62L boots from an SD card that is written with a TI WIC image. The WIC image
is written to the SD card with an etching tool; the application is then placed
on the card's FAT partition.

- For the image download and SD card setup, see :doc:`/getting_started/am62l/board_setup`.
- For loading the application from the SD card, see :doc:`/getting_started/am62l/flash_hello_world`.
