LCD Segment Display (Auxdisplay)
#################################

.. rst-class:: ti-subtitle

`Auxdisplay Zephyr Documentation <https://docs.zephyrproject.org/4.4.0/hardware/peripherals/auxdisplay.html>`_

.. important::

   The hardware LCD segment display controller is present only on the
   **MSPM0L series** (``lp_mspm0l2228``).  MSPM0G and MSPM33 devices do not
   have an LCD controller.

.. contents::
   :depth: 1
   :local:
   :class: hidden-title

Overview
========

The MSPM0L2228 integrates a hardware LCD segment display controller (TRM
Chapter 20) that directly drives COM and SEG voltage lines of a passive
LCD panel.  The controller generates the multiplex waveforms, manages
display and blinking memory, and provides an on-chip voltage generator for
bias voltages.

The Zephyr driver (``auxdisplay_mspm0_lcd``) exposes this hardware through
the standard auxiliary display API (``<zephyr/drivers/auxdisplay.h>``).
The configuration is split across two devicetree nodes:

- **``ti,mspm0-lcd``** — the hardware controller: mux mode, bias, clock
  divider, voltage source, and the COM / SEG pin lists.
- **``slcd-panel``** — a child node describing the physical glass: segment
  type (7 / 14), character positions, and the mapping from character
  segments to hardware pin/COM indices.

``CONFIG_AUXDISPLAY_MSPM0_LCD`` is selected automatically when an enabled
``ti,mspm0-lcd`` node is present.

Features Supported
==================

- Character output: :c:func:`auxdisplay_write` accepts ASCII text and
  converts characters to 7-segment or 14-segment patterns.  The cursor
  advances right automatically and wraps at the end of the display.
- Display on/off: :c:func:`auxdisplay_display_on`,
  :c:func:`auxdisplay_display_off`
- Clear all segments: :c:func:`auxdisplay_clear`
- Cursor position: :c:func:`auxdisplay_cursor_position_set` (absolute and
  relative), :c:func:`auxdisplay_cursor_position_get`
- Display capabilities query: :c:func:`auxdisplay_capabilities_get` —
  returns columns, rows, and segment type
- **Custom indicators** — individual non-character segments (decimal
  points, colons, degree symbol, minus sign):
  :c:func:`auxdisplay_custom_indicator_set`
- **Hardware all-segment blink**: :c:func:`auxdisplay_position_blinking_set_enabled`
  toggles all segments simultaneously using the built-in LCD blink
  clock.  Blink rate is set by the ``blink-rate`` devicetree property.
  Hardware blinking is **only available for mux modes Static–4-mux**;
  returns ``-ENOTSUP`` for 5-mux through 8-mux.
- Mux modes: Static, 2-mux, 3-mux, 4-mux, 5-mux, 6-mux, 7-mux, 8-mux
- Bias modes: Static (no bias), 1/3 bias, 1/4 bias
- Voltage sources: internal AVDD divider, external reference, charge pump
  (see ``voltage-source`` property values below)
- Configurable frame clock divider (``frequency-divider`` property)
- Low-power waveform mode (``LCDLP``) — reshuffles drive timeslots to
  reduce peak current; set via ``low-power`` DT property
- Up to 64 LCD IO pins configurable as COM or SEG lines

Features NOT Supported
======================

The following Zephyr auxdisplay API operations are not implemented:

- Cursor visibility (``auxdisplay_cursor_set_enabled``) — no cursor concept
  on segment displays
- Cursor shift (``auxdisplay_cursor_shift_set``)
- Display position (``auxdisplay_display_position_set/get``)
- Brightness control (``auxdisplay_brightness_set/get``) — contrast is
  fixed at init time by the ``voltage-source`` configuration
- Backlight (``auxdisplay_backlight_set/get``) — no backlight
- Busy check (``auxdisplay_is_busy``)
- Custom characters (``auxdisplay_custom_character_set``) — the 7-segment
  and 14-segment font is fixed in the driver
- Custom command (``auxdisplay_custom_command``)

The following hardware capabilities have no Zephyr auxdisplay API mapping:

- Per-segment individual blinking (available for Static–4-mux in hardware
  via blinking memory)
- Interrupt on frame start
- Charge pump voltage boost (``LCDVBSTEN``)

Enabling the Driver
===================

The ``lcd0`` node is pre-configured in the ``lp_mspm0l2228`` board
devicetree.  Enable the node and add the ``auxdisplay_0`` alias:

.. code-block:: devicetree

   auxdisplay_0: &lcd0 {
           status = "okay";
   };

.. code-block:: kconfig

   CONFIG_AUXDISPLAY=y

The full panel configuration (COM/SEG pins, segment-type, position maps)
is already set in ``lp_mspm0l2228.dts`` and does not need modification for
the on-board display.

Devicetree Properties
=====================

LCD controller node (``compatible = "ti,mspm0-lcd"``)
------------------------------------------------------

Include ``<zephyr/dt-bindings/auxdisplay/ti-mspm0-lcd.h>`` for the
constant names.

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Property
     - Description
   * - ``mux-mode``
     - Multiplexing mode.  ``MSPM0_LCD_MUX_MODE_STATIC`` (0) through
       ``MSPM0_LCD_MUX_MODE_8`` (7).  The number of COM lines equals the
       mux factor; higher mux allows more segments per SEG pin.
   * - ``bias-mode``
     - Bias voltage mode: ``MSPM0_LCD_BIAS_MODE_STATIC`` (0),
       ``MSPM0_LCD_BIAS_MODE_1_3`` (1/3 bias, 3 intermediate levels), or
       ``MSPM0_LCD_BIAS_MODE_1_4`` (1/4 bias, 4 intermediate levels).
       1/2 bias mode is **not** supported by the hardware.
   * - ``frequency-divider``
     - LCD clock divider, range 1–8.  Determines the LCD frame rate:
       ``f_frame = f_LFCLK / ((divider) × 2 × (mux_factor))``.
       The LP-MSPM0L2228 board default is ``3``.
   * - ``voltage-source``
     - Source and topology for the LCD bias voltage generator:

       - ``MSPM0_LCD_VOLTAGE_SOURCE_EXT_REF_EXT_DIV`` — external reference + external resistor ladder
       - ``MSPM0_LCD_VOLTAGE_SOURCE_EXT_REF_INT_DIV`` — external reference + internal resistor ladder
       - ``MSPM0_LCD_VOLTAGE_SOURCE_AVDD_INT_DIV`` — AVDD + internal resistor ladder (**LP-MSPM0L2228 default**)
       - ``MSPM0_LCD_VOLTAGE_SOURCE_AVDD_EXT_DIV`` — AVDD + external resistor ladder
       - ``MSPM0_LCD_VOLTAGE_SOURCE_CHARGE_PUMP_EXT`` — charge pump, external supply on R33/R13
       - ``MSPM0_LCD_VOLTAGE_SOURCE_CHARGE_PUMP_INT_REF`` — charge pump, internal VREF
       - ``MSPM0_LCD_VOLTAGE_SOURCE_CHARGE_PUMP_AVDD`` — charge pump powered from AVDD

   * - ``lcd-com-pins``
     - Required array of LCDIO pin indices (0–63) to use as COM lines, in
       COM order (index 0 = COM0).
   * - ``lcd-seg-pins``
     - Required array of LCDIO pin indices (0–63) to use as SEG lines.
   * - ``blink-rate``
     - Hardware blink prescaler (``MSPM0_LCD_BLINK_RATE_DIV_2`` through
       ``MSPM0_LCD_BLINK_RATE_DIV_256``).  Blink clock =
       ``f_frame / 2^(blink-rate+1)``.  Default: ``3`` (÷16, blink period
       ≈ 16 frames on + 16 frames off).  Only effective for mux modes
       Static–4-mux.
   * - ``charge-pump-frequency``
     - Charge pump clock in Hz (4096–455 Hz).  Only applicable when
       ``voltage-source`` is a charge pump variant.  Default: ``4096`` Hz.
   * - ``low-power``
     - Boolean.  Enables low-power waveform mode (``LCDLP = 1``):
       reshuffles drive timeslots to group identical voltage levels
       together, reducing switching current.

Panel child node (``compatible = "slcd-panel"``)
-------------------------------------------------

.. list-table::
   :header-rows: 1
   :widths: 28 72

   * - Property
     - Description
   * - ``columns``
     - Number of character positions on the display.
   * - ``rows``
     - Number of character rows (typically ``1`` for segment displays).
   * - ``segment-type``
     - Segments per character: ``7`` (A–G, digits 0–9), ``14`` (A–N,
       digits 0–9 + A–Z), or ``16`` (not yet supported).
   * - ``segment-pins``
     - 2-D array of LCDIO pin indices, ``[columns × segments]`` elements.
       Row ``i``, column ``j`` gives the pin controlling segment ``j`` of
       character position ``i``.
   * - ``segment-coms``
     - 2-D array of COM indices (0-based), same dimensions as
       ``segment-pins``.  Gives the COM line for each segment.
   * - ``num-indicators``
     - Count of special indicators (decimal points, colons, symbols).
   * - ``indicator-pins``
     - 1-D array of LCDIO pin indices, one per indicator.
   * - ``indicator-coms``
     - 1-D array of COM indices, one per indicator.
   * - ``col-indicators``
     - Array of length ``columns - 1``.  Each entry is the indicator index
       of the colon between that column gap, or ``0xFF`` for no colon.
   * - ``rotated``
     - Boolean.  Display mounted 180° — driver mirrors left/right.

LP-MSPM0L2228 Panel
-------------------

The on-board display is a **14-segment, 6-digit** panel configured in the
board DTS with:

- 4-mux mode, 1/3 bias, AVDD internal divider
- COM pins: LCDIO 24, 42, 43, 44 (4 COM lines)
- SEG pins: LCDIO 18–20, 23, 36–41, 45–58 (24 SEG lines)
- **9 indicators**: P1–P5 (decimal points), COL2/COL3 (colons between
  digit pairs), °C symbol, minus sign (DP)

Usage
=====

Write Characters
----------------

.. code-block:: c

   #include <zephyr/device.h>
   #include <zephyr/drivers/auxdisplay.h>

   static const struct device *const lcd =
           DEVICE_DT_GET(DT_NODELABEL(auxdisplay_0));

   /* Display "HELLO " on the 6-digit panel */
   const uint8_t msg[] = "HELLO ";
   auxdisplay_write(lcd, msg, sizeof(msg) - 1);

Write at a Specific Position
-----------------------------

.. code-block:: c

   /* Move cursor to position 3 (4th character), then write */
   auxdisplay_cursor_position_set(lcd, AUXDISPLAY_POSITION_ABSOLUTE, 3, 0);
   const uint8_t num[] = "42";
   auxdisplay_write(lcd, num, sizeof(num) - 1);

Custom Indicators
-----------------

The LP-MSPM0L2228 panel has 9 indicators.  Indicator indices:

.. list-table::
   :header-rows: 1
   :widths: 10 90

   * - Index
     - Symbol
   * - 0–4
     - Decimal points P1–P5 (after digits 1–5)
   * - 5
     - Colon COL2 (between digits 2 and 3)
   * - 6
     - Colon COL3 (between digits 4 and 5)
   * - 7
     - Degree Celsius (°C) symbol after digit 5
   * - 8
     - Minus / DP sign before digit 1

.. code-block:: c

   /* Turn on the decimal point after digit 1 */
   auxdisplay_custom_indicator_set(lcd, 0, true);

   /* Turn on the colon between digits 2 and 3 */
   auxdisplay_custom_indicator_set(lcd, 5, true);

Hardware Blink
--------------

.. code-block:: c

   auxdisplay_display_on(lcd);
   auxdisplay_position_blinking_set_enabled(lcd, true);   /* all segments blink */
   auxdisplay_position_blinking_set_enabled(lcd, false);  /* stop blinking */

.. note::

   Hardware blinking applies to **all** segments simultaneously; individual
   segment blinking is not available through the Zephyr API.

   Blink rate is fixed at boot by the ``blink-rate`` DT property.  The
   default (``3`` = ÷16) gives a blink period of about 16 LCD frames.

Samples
=======

In-tree
-------

- `Auxdisplay Digits Sample <https://docs.zephyrproject.org/4.4.0/samples/drivers/auxdisplay_digits/README.html>`_ —
  scrolls digits and letters across the display using
  :c:func:`auxdisplay_write` with a moving window.  Listed as
  ``platform_allow: lp_mspm0l2228`` in ``sample.yaml``.  No board overlay
  required; the board DTS already enables the panel.
- `Auxdisplay Sample <https://docs.zephyrproject.org/4.4.0/samples/drivers/auxdisplay/README.html>`_ —
  basic write demonstration using the standard auxdisplay API.

Applications (``applications/rtc_temp_lcd/``)
---------------------------------------------

- **rtc_temp_lcd** — multi-state temperature monitor for ``lp_mspm0l2228``
  using five on-chip peripherals with no external components:

  - **ADC** — samples the die temperature sensor every 1 s (internal
    1.4 V bandgap VREF, 3-sample average)
  - **RTC** — tracks date and time; seeded from the build UTC timestamp
    at boot
  - **auxdisplay** — drives the onboard 6-digit 14-segment LCD
  - **GPIO** — S2 (PA18) and S3 (PB8) push-buttons for display navigation
  - **HWINFO** — detects watchdog reset at boot

  Three display states cycled with the buttons:

  .. list-table::
     :header-rows: 1
     :widths: 15 35 50

     * - State
       - LCD
       - Notes
     * - ``TEMP``
       - ``  49.0 °C``
       - °C indicator (COL4) lit
     * - ``TIME``
       - ``HH:MM:SS``
       - Colon indicators (COL2, COL3) lit
     * - ``DATE``
       - ``DD.MM.YY``
       - Decimal-point indicators (P-dots) lit

  S2 steps backward, S3 steps forward.  Auto-returns to ``TEMP`` after
  10 s of inactivity.

  Two threads: **adc_thread** reads temperature every 1 s and logs
  WARMING/COOLING events (>3 °C delta) and a min/max/current summary
  every 10 s to UART; **main** refreshes the LCD at 250 ms.

Tests
=====

TI-SDK (``tests/drivers/auxdisplay/auxdisplay_mspm0/``)
-------------------------------------------------------------

A dedicated ztest suite exercises the full driver API on
``lp_mspm0l2228``.  Coverage includes:

- Capability reporting (columns, rows, segment type)
- Display on / off, clear
- Cursor positioning — absolute, relative, out-of-bounds error return
- Digit and letter rendering, including lowercase-to-uppercase folding for
  letters that are not representable in lowercase on a 14-segment display
- Decorator characters: ``.`` advances the decimal-point indicator of the
  preceding digit; ``:`` activates the colon indicator between digit pairs
  without advancing the cursor
- All 9 custom indicators toggled individually and together; out-of-range
  index returns ``-EINVAL``
- Hardware blink enable/disable, and blink + clear interaction
- Write while display is off — data is written to the shadow register and
  appears when ``display_on()`` is called
- Rotated panel encoding: symmetric digits (0, 2, 8) vs. asymmetric
  (6 ↔ 9 swap when mounted upside-down)
- Counter stress: 500 iterations of cursor-reset + 6-digit write at 20 ms
  intervals

Several cases drive physical glass and are meant to be visually verified
on hardware in addition to checking return codes.
